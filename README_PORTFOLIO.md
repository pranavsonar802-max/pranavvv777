## 💻 How to Run the Website Locally

1. Open a terminal in this folder:
   ```bash
   node server.js
   ```
2. Open your browser and navigate to:
   ```text
   http://localhost:3000/
   ```
3. To view your Research Paper directly:
   ```text
   http://localhost:3000/RESEARCH_PAPER_PRANAV_SONAR.html
   ```
